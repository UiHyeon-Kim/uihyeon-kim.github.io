사진·맵·플레이 기록

사용자가 고르거나 촬영한 사진은 기기에서 분석하여 맵을 만듭니다. 제작 이미지, 맵 이름과 발판, 개인 기록·고스트, 즐겨찾기와 전시관 설정은 앱의 기기 저장 공간에 보관합니다. 개발자 서버나 광고 서비스로 사진·맵·플레이 입력을 전송하지 않으며, 원본 앨범 사진을 변경하지 않습니다.

사진은 시스템 사진 선택기를 통해 선택한 항목만 읽습니다. 촬영은 외부 카메라 앱을 이용하며, 맵 제작에 사용한 임시 촬영 파일은 처리 후 정리합니다. 보관한 맵의 이미지와 기록은 사용자가 삭제할 때까지 기기에 남습니다.

계정과 온라인 기능

현재 버전은 SNAPBOUND 회원 가입을 받지 않습니다. 친구, 맵 게시·공유, 온라인 순위 및 클라우드 백업을 제공하지 않으며 이 기능을 위한 서버 전송도 하지 않습니다. Google Play 구매 계정은 SNAPBOUND 회원 계정과 다릅니다.

광고와 Google 서비스

광고가 활성화된 버전은 Google Mobile Ads와 User Messaging Platform을 사용합니다. Google 광고 서비스는 광고 제공·이용 분석·부정 사용 방지를 위해 IP 주소(대략적인 위치 추정에 사용), 앱 및 광고 상호작용, 진단 정보, 광고 ID·앱 세트 ID 등의 기기·계정 식별자를 처리할 수 있습니다. 전송에는 TLS 암호화를 사용합니다.

SNAPBOUND는 청소년 보호 광고 설정을 적용하여 맞춤형 광고와 리마케팅을 비활성화합니다. 이는 광고 SDK의 모든 데이터 처리가 중단된다는 뜻은 아닙니다. 필요한 지역에서는 동의 안내를 표시하며, 앱 상점에 광고 개인정보 설정이 표시되면 선택을 다시 변경할 수 있습니다. Android 설정에서 광고 ID를 재설정하거나 삭제할 수도 있습니다.

광고 서비스의 처리·보관 및 국외 처리에 관한 내용은 Google 개인정보처리방침과 광고 SDK 데이터 안내를 확인해 주세요. SNAPBOUND는 사진이나 맵 내용을 광고 타기팅 값으로 보내지 않습니다.

구매

광고 제거 구매는 현재 판매하지 않으며 구매 확인 서버도 연결하지 않았습니다. 구매를 활성화하기 전에 처리 항목·제공 업체·보관 정책을 이 페이지에 반영합니다. 앱은 카드 번호나 Google 계정 비밀번호를 직접 입력받지 않습니다.

문의와 웹사이트

이메일로 문의하면 회신 주소, 문의 내용 및 직접 첨부한 자료를 문제 해결과 답변에 이용합니다. 문의 목적을 달성해 더 이상 필요하지 않은 정보는 삭제하며, 법령에 따라 보관해야 하는 정보가 있으면 해당 기간 동안만 보관합니다. 사진·비밀번호·구매 토큰 등 불필요한 민감 정보는 보내지 마세요. 열람·정정·삭제 요청도 같은 이메일로 접수합니다.

이 안내 사이트는 GitHub Pages에서 제공합니다. 페이지에 자체 분석 스크립트나 광고를 넣지 않습니다. 웹 요청 처리는 GitHub 개인정보처리방침의 적용을 받습니다.

보관 정보 삭제

앱의 내 공간에서 맵을 열고 ‘이 맵 삭제’를 선택하면 기기의 해당 맵·복사 이미지·연결 기록이 삭제됩니다. 원본 앨범 사진은 유지됩니다. 앱 삭제 또는 Android의 앱 저장 공간 초기화는 전체 로컬 데이터를 삭제합니다. 자동 클라우드 백업·복원은 제공하지 않습니다.

개발자는 사용자의 기기에만 있는 데이터를 원격으로 열람하거나 복원할 수 없습니다. Google이 처리하는 광고 관련 정보에 대한 선택과 권리 행사는 Google의 개인정보 안내 및 Android 설정을 확인해 주세요.

이용 연령과 변경 안내

이 앱의 목표 이용자는 만 13세 이상입니다. 생년월일을 입력받거나 이용자의 실제 나이를 추정하지 않습니다. 개인정보 처리 범위가 바뀌면 시행일과 이 방침을 갱신하며, 필요한 경우 앱에서도 안내합니다.
